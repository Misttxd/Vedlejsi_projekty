# Builder, Log4j2 a equals-hashCode

Cvičení rozšiřuje JavaFX hru o builder pro nastavení, logování a korektní porovnávání skóre.

## Funkce

- **Builder**: konfigurace hry přes třídu `Setting`.
- **Log4j2**: logování vybraných akcí a pohybu entit.
- **equals a hashCode**: logické porovnávání skóre.
- **Herní základ**: zachovaná JavaFX hra s dělem, střelami a UFO.
