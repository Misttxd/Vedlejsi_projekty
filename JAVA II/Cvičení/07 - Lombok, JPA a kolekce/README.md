# Lombok, JPA a kolekce

Cvičení obsahuje sadu menších úloh zaměřených na Lombok, práci s kolekcemi, logování a JPA entity.

## Funkce

- **Úklid krabic**: skládání krabic do police, vlastní výjimka a logování chybových stavů.
- **Cestovní agentura**: model osob a lístků s dědičností, `equals`, `hashCode` a `toString` přes Lombok.
- **JPA model měst**: entity `Country`, `City` a `Building` s vazbou město-budovy.
- **Criteria API**: dotaz pro výběr budov podle rozsahu počtu podlaží.
