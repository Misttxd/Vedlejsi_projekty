# Spring, OpenAPI klient a Thymeleaf

Vícemodulové cvičení propojuje Spring Boot server, generovaný OpenAPI klient a JavaFX hru.

## Obsah

- **java2-lab09-spring**: REST API pro hráče a skóre, doplněné o Thymeleaf stránku.
- **java2-lab09-gen-client**: klientský projekt pro komunikaci s REST API.
- **java2-lab09-game**: desktopová hra napojená na server.

## Funkce

- **REST API**: endpointy pro hráče a skóre.
- **OpenAPI klient**: příprava na generování klientského kódu.
- **Thymeleaf**: webová tabulka výsledků.
- **Propojení hry se serverem**: hra může načítat a ukládat data přes klienta.
