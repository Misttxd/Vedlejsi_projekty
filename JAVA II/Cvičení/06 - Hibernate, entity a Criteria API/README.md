# Hibernate, entity a Criteria API

Cvičení je zaměřené na JPA entity, vazby mezi nimi a dotazování přes Criteria API.

## Funkce

- **Entity model**: hráči, hry a skóre jsou připravené jako JPA entity.
- **Dědičnost her**: model obsahuje specializace herních tříd.
- **Hibernate processor**: projekt pracuje s generovanými metamodel třídami.
- **Criteria API**: repository je určené pro filtrované dotazy nad skóre a hrami.
