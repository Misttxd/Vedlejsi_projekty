# Maven a ASCII art

Úvodní Maven projekt pro práci s parametry příkazové řádky a převodem textu na ASCII art.

## Funkce

- **Maven projekt**: základní struktura aplikace s testy a zdrojovými prostředky.
- **Vstup textu**: aplikace pracuje s textem z argumentů nebo konzole.
- **ASCII art**: převod vstupního textu přes školní knihovnu.
- **Logování**: projekt obsahuje konfiguraci Log4j2.
