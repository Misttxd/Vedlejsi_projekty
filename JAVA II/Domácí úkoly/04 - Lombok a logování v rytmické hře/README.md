# Lombok a logování v rytmické hře

Domácí úkol pracuje s rytmickou JavaFX hrou a doplňuje části požadované v zadání okolo konfigurace, logování a jednoduššího modelového kódu.

## Funkce

- **Rytmická hra**: noty padají do jednotlivých drah a hráč je trefuje při průchodu hit zónou.
- **Nastavení hry**: ovládání hlasitosti a kláves pro jednotlivé dráhy.
- **Mapy a skóre**: načítání map a ukládání výsledků hry.
- **Logování**: projekt obsahuje konfiguraci Log4j2.
