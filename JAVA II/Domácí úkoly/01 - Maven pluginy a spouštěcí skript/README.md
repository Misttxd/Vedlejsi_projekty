# Maven pluginy a spouštěcí skript

Domácí úkol doplňuje Maven konfiguraci hry tak, aby bylo možné vytvořit JAR balíček s knihovnami a spouštěcí skript.

## Funkce

- **Maven balení**: konfigurace pro sestavení aplikace a závislostí.
- **Spouštěcí skript**: soubor `run.bat` pro spuštění hry mimo IDE.
- **JavaFX hra**: jednoduchý herní projekt s grafickými entitami a mapami.
