# Moduly a knihovna pro ukládání dat

Domácí úkol odděluje část práce s mapami a skóre do samostatné knihovny.

## Obsah

- **RHYTM_GAME**: hlavní JavaFX rytmická hra.
- **mapManagement**: samostatná knihovna pro práci s mapami a skóre.

## Funkce

- **Více Maven projektů**: hra a knihovna jsou oddělené.
- **Mapy a skóre**: modely `MapInfo`, `Score` a repository jsou přesunuté do knihovny.
- **Opětovné použití kódu**: herní projekt může využívat samostatný mapovací modul.
