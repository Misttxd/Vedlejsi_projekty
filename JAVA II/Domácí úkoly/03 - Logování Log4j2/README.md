# Logování Log4j2

Domácí úkol přidává do rytmické hry knihovnu Log4j2 a základní logovací konfiguraci.

## Funkce

- **Log4j2 konfigurace**: logování do konzole a souboru.
- **Více úrovní logů**: projekt používá informační i chybové logovací zprávy.
- **Rytmická hra**: zachovává základní herní smyčku, skóre, noty a mapy.
- **Maven závislosti**: projekt obsahuje potřebné knihovny pro logování.
