# Webová stránka s tabulkou entit

Domácí úkol rozšiřuje Spring server o jednoduchou webovou stránku s tabulkou entit a možností mazání záznamů.

## Funkce

- **Entity User a Role**: základní JPA model.
- **REST API**: CRUD operace pro uživatele.
- **Thymeleaf stránka**: tabulka uživatelů na webu.
- **Mazání záznamů**: webový controller umožňuje odstranit uživatele z databáze.
