# Spring REST API

Domácí úkol se Spring Boot serverem pro jednoduchou správu uživatelů.

## Funkce

- **Entity User a Role**: základní JPA model pro uživatele a role.
- **REST API**: CRUD operace pro uživatele pod `/api/users`.
- **Webová stránka**: Thymeleaf stránka se seznamem uživatelů a mazáním záznamů.
- **H2 databáze**: lokální databáze pro vývoj a testování.
