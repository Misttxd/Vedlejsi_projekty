# Internacionalizace

Domácí úkol doplňuje rytmickou hru o lokalizované texty přes Java `ResourceBundle`.

## Funkce

- **ResourceBundle**: texty jsou uložené v `messages.properties` souborech.
- **Čeština a angličtina**: projekt obsahuje českou a anglickou lokalizaci.
- **Nastavení hry**: lokalizované menu a obrazovky nastavení.
- **Rytmická hra**: zachovává herní mechaniky, mapy a skóre.
