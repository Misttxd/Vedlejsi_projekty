# Vlákna a internacionalizace

Domácí úkol rozšiřuje rytmickou hru o samostatně běžící herní entity a lokalizované texty.

## Funkce

- **Vlákna**: vybrané herní objekty mohou měnit stav nezávisle na hlavní smyčce.
- **Synchronizace**: práce s kolekcemi entit je připravená na bezpečnější průběh při souběhu.
- **Lokalizace**: texty hry jsou oddělené do resource bundle souborů.
- **Rytmická mechanika**: zachovává skóre, combo, overdrive a vyhodnocení zásahů not.
