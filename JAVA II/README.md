# Jazyk Java II

Tato složka obsahuje vypracovaná cvičení, domácí úkoly a semestrální projekt z předmětu Java II. Uspořádání navazuje na styl repozitáře Vedlejší projekty: krátké popisy, samostatné README soubory v podsložkách a zdrojové kódy bez lokálních build výstupů.

## Obsah

- [Cvičení](./Cvičení/README.md): menší laboratorní projekty zaměřené na Maven, Log4j2, Lombok, JPA, Spring, reflection a lokalizaci.
- [Domácí úkoly](<./Domácí úkoly/README.md>): navazující úkoly nad rytmickou hrou a Spring serverem.
- [Semestrální projekt - Rytmická hra](<./Semestrální projekt - Rytmická hra/README.md>): JavaFX hra doplněná o Spring Boot server pro správu hráčů, map a skóre.
- [Zadání](./Zadání/README.md): přepisy zadání cvičení a domácích úkolů.
