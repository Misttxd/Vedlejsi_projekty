# Technologie a Aplikace Mobilních Zařízení (TAMZ)

Tato složka obsahuje menší webové a mobilní projekty vytvořené v rámci předmětu TAMZ. Projekty ukazují práci s Ionic komponentami, lokálním úložištěm, HTTP požadavky, mapou v Reactu a jednoduchou 2D hrou ve Phaseru.

## Obsah:
- [Semestrální termíny](./Semestrální%20termíny/README.md) - Aplikace pro sledování důležitých termínů v semestru.
- [Lokální paměť](./Lokální%20paměť/README.md) - Jednoduchý seznam záznamů ukládaný do lokální paměti prohlížeče.
- [BMI kalkulačka](./BMI%20kalkulačka/README.md) - Kalkulačka BMI s historií výpočtů.
- [HTTP API aplikace](./HTTP%20API%20aplikace/README.md) - Ukázka GET/POST požadavků a práce s tokenem.
- [Mapa a lokace](./Mapa%20a%20lokace/README.md) - Ionic React aplikace s vyhledáváním míst a zobrazením markerů na mapě.
- [Phaser hra](./Phaser%20hra/README.md) - 2D arkádová hra ve Phaser 3 s tilemapou, skórováním a PWA podporou.
