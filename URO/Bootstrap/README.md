# Portfolio Landing Page (React)

Responzivní portfolio/landing page vytvořená v Reactu a TypeScriptu. Projekt slouží jako prezentační web s úvodní sekcí, technologiemi, ukázkovými projekty a kontaktním formulářem.

## Popis funkčnosti
- Zobrazuje osobní portfolio s navigací mezi sekcemi.
- Obsahuje animovanou hero část, orbitální grafiku a interaktivní prvky.
- Představuje technologie, zkušenosti a vybrané projekty.
- Obsahuje kontaktní formulář vytvořený pomocí `react-hook-form`.
- Využívá responzivní layout pro desktop i mobil.

## Technologie
- React
- TypeScript
- Vite
- Framer Motion
- Lucide React
- React Hook Form
