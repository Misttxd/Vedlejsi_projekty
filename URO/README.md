# Uživatelská rozhraní (URO)

Tato složka obsahuje projekty z předmětu URO zaměřené na tvorbu uživatelských rozhraní v různých technologiích. Jednotlivé projekty ukazují návrh obrazovek, práci s formuláři, stavem aplikace a základní interakcí uživatele.

## Obsah:
- **[Portfolio Landing Page (React)](./Bootstrap/README.md)** - Responzivní portfolio/landing page vytvořená v Reactu, TypeScriptu a Vite.
- **[Task Manager (Python)](./Task%20Manager%20%28Python%29/README.md)** - Aplikace pro správu úkolů vytvořená v Pythonu pomocí knihovny `customtkinter`.
- **[Task Manager (Qt)](./Task%20Manager%20%28Qt%29/README.md)** - Desktopová varianta správce úkolů vytvořená v C++ a Qt Widgets.
- **URO_sketch.png** - Návrhový sketch/prototyp rozhraní.
