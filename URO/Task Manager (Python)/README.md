# Task Manager (Python)

Aplikace pro správu úkolů vytvořená v Pythonu pomocí knihovny `customtkinter`. Projekt ukazuje desktopové GUI se seznamem úkolů, filtrováním a nastavením vzhledu.

## Popis funkčnosti
- Umožňuje přidávat nové úkoly s názvem, kategorií a termínem.
- Zobrazuje úkoly v přehledném scrollovatelném seznamu.
- Podporuje filtry **Všechny úkoly**, **Dnes** a **Důležité**.
- Umožňuje označit úkol jako dokončený nebo jej odstranit.
- Obsahuje okno nastavení s přepínáním světlého a tmavého režimu.
- Používá vlastní date picker `CTkDatePicker`.

## Technologie
- Python
- CustomTkinter
- CTkTable
- Tkinter

## Soubory
- **main.py**: Hlavní logika aplikace a tvorba GUI.
- **requirements.txt**: Seznam Python závislostí.
- **CTkDatePicker/**: Lokální komponenta pro výběr data.
- **Sketch_URO.png**: Návrh rozhraní.
